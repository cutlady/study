# 学习过程记录：坚持 → 系统设计 → 个人系统 v1.0

> 日期：2026-05-14
> 来源：[每日学习] 坚持 + 延伸对话
> 目的：记录完整思考演变过程，日后可回溯

---

## 第一阶段：打破"坚持 = 毅力"的直觉

### 我的初始想法
我一直认为坚持就是毅力。想做一件事、做好一件事，靠毅力去完成就够了。

### 受到的冲击
AI 提出"坚持不是意志力的胜利，而是系统的胜利"——这个说法超出了我的想象。

### 关键转折
我开始反思：**之前之所以没坚持住，不是因为我弱，而是因为没有经过可靠的设计。**

AI 进一步拆解了毅力的致命缺陷：
- 毅力不是恒定资源，它像手机电量，每天早上满格，随着决策和疲劳消耗
- 靠毅力坚持，是用最稀缺的资源驱动最重要的目标——这在设计上就是脆弱的

这让我意识到，我之前失败的那些事，不是因为我不够狠，而是因为**没有给低电量的自己留一条活路。**

---

## 第二阶段：追问坚持与专注的关系

### 我的疑问
如果坚持靠系统设计而不是毅力，那经过系统设计形成的坚持，和专注有什么关联？

### 核心发现
**坚持和专注共享同一个瓶颈——决策带宽。**

每天约 30-50 次有效决定。如果"要不要做""做什么""做多久"这些决策消耗了预算，剩下的精力既支撑不了坚持，也支撑不了专注。

### 系统的真正作用
系统消除了"要不要做"这个最大的决策黑洞。省下来的决策带宽，可以全部投给"做多深"——也就是专注。

### 更深一层：神经髓鞘化
重复做一件事，大脑的神经能耗会下降。坚持撑过了髓鞘化之前的高能耗阶段，专注就会自然变深。

**我之前的感受"我不够专注"，可能实际上是：每次学习都是新的（没重复到髓鞘化）→ 每次都很费力 → 觉得自己不行 → 放弃。**

## 第三阶段：设计多件事系统的挑战

### 我的想法
能不能设计一个每天做多件事的系统？比如早上读书，晚上跑步，两件事可能没什么关联。甚至三件、四件。

### 关键认知：切换成本
单件事系统的瓶颈是"要不要做"，多件事系统的瓶颈是"切换成本"——大脑从任务 A 切换到 B，平均需要 23 分钟才能回到深度状态。

### 设计原则
1. **认知模式匹配**：相同认知模式的事放在一起，不同模式的事拉开距离
2. **能量匹配**：高认知任务配高能量时段（早上），低认知任务配低能量时段（晚上）
3. **保底设计**：每件事都必须有低电量版本

## 第四阶段：面对自己的失败——通勤学英语

### 我的经历
我之前安排下班后通勤时段学英语或读书，但是很快就觉得无法进行了。

### 分析：为什么崩了
- 下班后决策预算 ≈ 0（已被工作耗尽）
- 通勤本身消耗认知（注意环境、过滤噪音）
- 学英语是主动记忆，高认知负载
- **用仅剩 5% 电量跑需要 80% 电量的任务 → 失败是设计决定的**

### 方案："认知格式化"
同一件事，把认知格式从"创造新连接"转为"强化已有连接"：
- 晚上不学新英语，而是复习早上的内容
- 早上摄入，晚上巩固——配合睡眠完成记忆强化

**我放弃通勤学习之后，曾对自己判断："我果然不够自律。"但实际因果链是：任务格式和认知状态不匹配 → 每次都失败 → 大脑形成痛苦记忆 → 回避行为。这不是性格缺陷。**

## 第五阶段：设计我的个人系统 v1.0

### 时间排程

| 时段 | 任务 | 认知类型 |
|---|---|---|
| 08:00-08:30 | 读书 | 高认知（新摄入） |
| 09:15-10:00 | 每日学习 | 高认知（深加工） |
| 19:00-19:30 | 回顾学习 | 低认知（巩固） |
| 20:10 | 跑步 | 体力（零认知） |

### 两个缓冲带
- 08:30-09:15（45min）：读书 → 学习过渡
- 19:30-20:10（40min）：学习 → 跑步过渡

### 保底设计

| 任务 | 标准模式 | 低电量模式 |
|---|---|---|
| 读书 | 正常阅读 | 读一页 |
| 每日学习 | 完整笔记 | 学一个概念 |
| 回顾 | 回顾笔记 | 脑子里过一遍 |
| 跑步 | 正常跑步 | 换好衣服，出门跑一公里 |

**核心规则：低电量模式也计入完成。不中断比多做重要。**

### 跑步的特殊处理
跑步不止是时间问题——启动摩擦大。保底"换好衣服出门跑一公里"是两层设计：
- 换好衣服 = 物理绑架（穿都穿了，不跑更奇怪）
- 跑一公里 = 最小可计数完成量（约 6-8 分钟）

## 关键认知转变总结

```
之前                            →  现在
──────────────────────────────────────────────────────
坚持 = 毅力                      →  坚持 = 系统设计
没坚持住 = 我不够自律             →  没坚持住 = 系统和认知规律不匹配
专注靠意志力                     →  专注靠系统释放的决策带宽
晚上可以做任何事                 →  晚上只做低认知或体力任务
失败是性格缺陷                   →  失败是设计漏洞
"做完整"才算完成                 →  "做最小的一步"就算在轨道上
```
