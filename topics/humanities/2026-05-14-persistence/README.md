# 坚持 — 2026-05-14

## 0. 概念性描述 (Why → How → What)

### What（是什么）
**坚持不是意志力的胜利，而是系统的胜利。** 它是通过建立简单可重复的行为模式，在动力起伏时依然能维持行动方向的能力。

### How（怎么做到的）
- **降低门槛**：每天只做一点点，比一次做好更多更重要
- **移除决策**：把想坚持的事变成默认选项（比如：固定时间、固定地点）
- **接受波动**：状态好的日子多做，状态差的日子做最少量的保底
- **持续记录**：追踪次数比追踪质量更能维持动力

### Why（为什么有用）
因为人类的动力（motivation）天生波动，而问题（problem）不会随动力消失而消失。坚持的本质是**在低动力日依然能行动**的机制。

## 3. 费曼检验（用自己的话讲明白）

> 如果我给 12 岁的小朋友讲"坚持"：

你想学会滑板。第一天摔了，没事。第二天又摔了，有点疼。第三天你可能不想去了。

坚持不是说"我不怕摔"——大人说的"有毅力"其实是个谎言。真相是：**你不可能永远不怕摔。**

真正的高手只是做了一件事：他们告诉自己，"今天就滑 5 分钟就行。"

5 分钟滑完，你通常会发现：其实也没那么糟。有时候你甚至想多滑一会儿。有时候真的只滑了 5 分钟就回家了。**重点是，你去了。**

365 天每天 5 分钟，比 30 天每天 2 小时，能让你滑得更好。因为你的大脑每天都在偷偷练习，哪怕你没注意到。

## 4. 建立联系

| 已知概念 | 与"坚持"的关系 |
|---|---|
| **复利** | 坚持是时间的复利。每天 1% 进步，一年 37 倍；但断一天就可能倒退 |
| **习惯回路** | 坚持不是靠意志力，而是靠 cue → routine → reward 的自运行 |
| **熵增** | 系统天然走向混乱；坚持是对抗熵增的低功耗手段 |
| **沉没成本** | 坚持容易变成"我投入太多不能放弃"——真正的坚持要区分"有意义的方向"和"绑架" |
| **反馈循环** | 记录坚持天数 → 看到 streak → 更有动力继续 → 正向循环 |

## 5. 输出总结

**一句话**

> 坚持不是每天都赢，而是不让停下来的那天变成最后一天。

**三个可操作的原则**

1. **最小行动** — 任何计划都要有个"低电量版"（比如：今天没时间，就写一行代码）
2. **不丢二连** — 可以休息一天，但绝不停两天。停一天是休息，停两天是放弃的开始
3. **身份优先** — 不要说"我在坚持学编程"，要说"我是一个每天写代码的人"。一旦行为变成身份，不做的成本会超过做的成本。
