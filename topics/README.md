# 每日学习项目

每天学习一个知识点，双线并行：

| 路线 | 领域 | 示例 |
|---|---|---|
| **技术线** | 编程、系统设计、工具、架构 | NATS, Timer, 数据库 |
| **人文线** | 思维模型、认知科学、哲学、方法论 | 选择, 坚持, 决策 |

遵循以下流程：

## 学习流程

1. **概念性描述** — AI 先给出简洁的概念框架（Why → How → What）
2. **知识定位** — 理解该知识点在更大体系中的位置
3. **动手实践** — 通过代码/实验验证理解
4. **费曼检验** — 用自己的话复述，发现盲区
5. **建立联系** — 和已知知识建立关联
6. **输出总结** — 写笔记，记录关键理解
