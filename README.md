|---|---|---|

## 学习流程

1. **概念性描述** — AI 先给出简洁的概念框架（Why → How → What）
2. **知识定位** — 理解该知识点在更大体系中的位置
3. **动手实践** — 通过代码/实验验证理解
4. **费曼检验** — 用自己的话复述，发现盲区
5. **建立联系** — 和已知知识建立关联
6. **输出总结** — 写笔记，记录关键理解
7. **整理成文** — 将笔记转化为可发布的公众号文章
