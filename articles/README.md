# 公众号文章

基于每日学习笔记整理，适合微信公众号发布。写给自己读的，语气要自然——像讲给朋友听。

## 排版速查

- **正文字号**：15px，颜色 #3f3f3f
- **标题字号**：18px，颜色 #333333
- **行间距**：1.75 倍
- **两端缩进**：10px
- **段间空行**：一个空行
- **禁用**：斜体、下划线、首行缩进、纯黑色

## 转换工具

```
python3 to_wechat.py <文章.md>
```

生成 `文章_wechat.html`，打开复制全部 HTML → 微信公众号编辑器 → 源代码模式 → 粘贴。

## 目录
```
articles/
  README.md
  to_wechat.py              # Markdown → 微信 HTML 转换器
  YYYY-MM-DD-主题.md         # 单篇成文
  YYYY-MM-DD-主题_wechat.html # 生成的 HTML（可删除）
```
